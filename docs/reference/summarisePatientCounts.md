# Summarise patient counts

Returns summary statistics about the number of subjects in adherence
data and drug exposure data.

## Usage

``` r
summarisePatientCounts(
  adherenceData = NULL,
  drugExposure = NULL,
  cdm = NULL,
  cohort = NULL,
  cohortId = NULL,
  n = 1
)
```

## Arguments

- adherenceData:

  Database table reference or data frame containing adherence
  calculation results, typically generated by \[calculateAdherence()\]
  or \[calculateAdherenceSlidingWindow()\].

- drugExposure:

  Database table reference or data frame containing drug exposure data
  with patient information, typically generated by
  \[generateChronicDrugExposure()\]. Required columns: person_id,
  drug_concept_id, drug_exposure_start_date, days_supply.

- cdm:

  (\`cdm_reference\`) A CDM reference object created with CDMConnector.

- cohort:

  (\`tbl\` or \`NULL\`) Optional cohort table reference for additional
  counts.

- cohortId:

  (\`numeric\` or \`NULL\`) Optional vector of cohort_definition_id
  values.

- n:

  (\`numeric(1)\`) Minimum number of rows per year for a person to be
  included in 'Yearly drug exposure record count' table. Default: 1.

## Value

Named list with patient count summaries.

## Examples

``` r
if (FALSE) { # \dontrun{
cdm <- mockDrugExposure()
conceptSet <- CodelistGenerator::getDrugIngredientCodes(cdm, name = "Atorvastatin")

drugExposure <- generateChronicDrugExposure(
  cdm = cdm,
  conceptSet = conceptSet,
  name = "drug_exposure"
)
adherenceData <- calculateAdherenceBatched(drugExposure, cdm, cma = "CMA5")

counts <- summarisePatientCounts(
  adherenceData = adherenceData,
  drugExposure = drugExposure,
  cdm = cdm
)
} # }
```
