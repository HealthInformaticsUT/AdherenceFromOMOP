# Calculate adherence (batched processing)

Calculates adherence in batches for large datasets.

## Usage

``` r
calculateAdherenceBatched(
  drugExposure,
  cdm,
  name = "adherenceFromOMOP_results",
  cma = c("CMA1", "CMA2", "CMA3", "CMA4", "CMA5", "CMA6", "CMA7", "CMA8", "CMA9"),
  medicationGroup = NULL,
  groupByRoute = FALSE,
  batchSize = 1000,
  ...
)
```

## Arguments

- drugExposure:

  Database table reference or data frame containing drug exposure data
  with patient information, typically generated by
  \[generateChronicDrugExposure()\]. Required columns: person_id,
  drug_concept_id, drug_exposure_start_date, days_supply.

- cdm:

  (\`cdm_reference\`) A CDM reference object created with CDMConnector.

- name:

  (\`character(1)\`) Name for the output table in the database.

- cma:

  (\`character\`) Vector of CMA types to calculate. Options: \`"CMA1"\`
  through \`"CMA9"\`. See \[AdhereR
  documentation\](https://www.adherer.eu/) for details on each CMA type.

- medicationGroup:

  (\`list\` or \`NULL\`) Named list where each element contains
  drug_concept_id values for a medication group. CMA is calculated
  separately for each group. If \`NULL\`, all medications are treated as
  one group.

- groupByRoute:

  (\`logical(1)\`) If \`TRUE\`, further splits each medication group by
  \`route_concept_id\`, calculating CMA separately for each route found
  within the group. Drug exposure records with a missing or zero
  \`route_concept_id\` remain part of the general ingredient-level
  group. Default: \`FALSE\`.

- batchSize:

  (\`numeric(1)\`) Number of subjects to process in each batch.
  Default: 1000. Increase for better performance with large datasets,
  decrease if running into memory issues.

- ...:

  Additional arguments passed to AdhereR CMA functions.

## Value

Database table reference containing adherence calculations.

## Examples

``` r
if (FALSE) { # \dontrun{
cdm <- mockDrugExposure()
conceptSet <- CodelistGenerator::getDrugIngredientCodes(cdm, name = "Atorvastatin")

drugExposure <- generateChronicDrugExposure(
  cdm = cdm,
  conceptSet = conceptSet,
  name = "drug_exposure"
)

adherenceData <- drugExposure |>
  calculateAdherenceBatched(cdm, cma = "CMA5", name = "adherence_results")
} # }
```
