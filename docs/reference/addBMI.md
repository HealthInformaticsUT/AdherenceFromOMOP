# adds bmi values to CMA values

adds bmi values to CMA values

## Usage

``` r
addBMI(adherenceData, cdm)
```

## Arguments

- adherenceData:

  Database table reference or data frame containing adherence
  calculation results, typically generated by \[calculateAdherence()\]
  or \[calculateAdherenceSlidingWindow()\].

- cdm:

  (\`cdm_reference\`) A CDM reference object created with CDMConnector.

## Value

Adherence data with BMI category information added.

## Examples

``` r
if (FALSE) { # \dontrun{
cdm <- mockDrugExposure()
chronicDrugExposure <- generateChronicDrugExposure(
  cdm = cdm,
  name = "chronic_drug_exposure_table",
  overwrite = T
)
CMA_values <- calculateAdherenceBatched(
  drugExposure = chronicDrugExposure,
  cdm = cdm, cma = "CMA5"
)
withBMI <- addBMI(CMA_values, cdm)
} # }
```
